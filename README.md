# Taltex Meathub – Online Food Ordering & Delivery Platform
Taltex Meathub is a modern web-based food ordering platform built for a restaurant specializing in fresh and fried rabbit meat.
The application enables customers to browse products, place orders, make payments, and receive delivery updates, while providing administrators with full control over products, orders, and sales data.
The platform is designed to be fast, secure, mobile-friendly, and scalable, supporting both customer-facing features and an admin management dashboard.

## Features
- Customer-Facing Features
  - Modern, responsive homepage with clear call-to-action (“Order Now”)
  - Product catalog with categories, images, pricing, and descriptions
  - Portion size and quantity selection
  - Shopping cart and checkout flow
  - Secure order placement with delivery details
  - Multiple payment options:
   - Mobile Money (MTN & Airtel)
   - Cash on Delivery
   - Order confirmation and status tracking
   - Contact and business information access
- Ordering & Delivery
   - Delivery zone and fee handling
   - Order status updates (Received, Preparing, Out for Delivery, Delivered)
   - Instant order notifications for administrators
   - Order confirmation for customers
   - Optional WhatsApp/SMS notification support
- Admin Dashboard
   - Secure admin authentication
   - Product management (add, edit, delete, update prices, upload images)
   - Order management with real-time status updates
   - Customer data visibility
   - Sales overview and basic performance insights
   - Promotions and featured products management (optional)
- Technical Highlights
  - Fast-loading, SEO-friendly architecture
  - Secure authentication and role-based access
  - Scalable backend powered by Supabase
  - Optimized data fetching and caching
  - Fully responsive design across mobile, tablet, and desktop
  
## Tech Stack
- React.js
- TypeScript
- Supabase as backend and database
- React Query for API data fetching
- Shadcn UI components
- RESTful API integration

## Purpose
This project was built to digitize Taltex Meathub’s food ordering and delivery process, reduce manual order handling, and provide customers with a seamless online ordering experience while giving administrators full visibility into sales, orders, and operations.
